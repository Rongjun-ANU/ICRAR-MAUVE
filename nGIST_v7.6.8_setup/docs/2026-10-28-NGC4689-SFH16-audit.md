These checks include complete FITS/HDF5 file contents, not just filenames,

`diff -u NGC4689/CONFIG NGC4689_SFH16/CONFIG` showed exactly these differences:
GENERAL.RUN_ID, GENERAL.OUTPUT, CONT.METHOD (ppxf -> false), GAS.METHOD
(ppxf -> false), and SFH.MDEG (12 -> 16). All other saved settings match.

spectra. The unrenamed `NGC4689_mask.fits` in the test directory is also
byte-identical to the original, but the correctly prefixed mask is the
checkpoint used by the masking dispatcher.

Conclusion: the saved inputs and configuration support using this completed
test as a controlled SFH MDEG comparison. The execution was not SFH-only,
but the upstream recomputation produced identical files. No assumption about
deterministic binning or KIN is needed for this conclusion.
